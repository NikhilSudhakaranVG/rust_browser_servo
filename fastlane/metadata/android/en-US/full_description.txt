"FOSS Browser" is a fully free (as in freedom) open source Android browser: privacy-friendly with a modern user interface. - Your privacy - your data.


-------------------------------------------------
<b>Pluggable Rendering Engines (Servo & WebView)</b>
-------------------------------------------------

FOSS Browser decouples UI controls from the underlying rendering engine using a modular abstraction layer:

• Android System WebView: Default, production-tested engine leveraging the system WebKit/Blink implementation.
• Servo Web Engine (Experimental): Next-generation, independent embeddable engine written in Rust with parallel layout and rendering via OpenGL ES.
• Runtime Switching: Easily switch between rendering engines via Developer Options.


-------------------------------------------------
<b>UI/Handling</b>
-------------------------------------------------

FOSS Browser uses the latest Material You design libraries. Following system day/night mode and a wallpaper-based theme are just two features of this library. The UI is optimized for one-hand use: all navigation controls are located at the bottom of the screen.

More features:

• Keep screen on.
• Open links in background.
• Restore tabs on restart.


-------------------------------------------------
<b>Privacy</b>
-------------------------------------------------

FOSS Browser uses domain profiles to protect your privacy. For each domain or standard profile, you can customize: AdBlock, JavaScript, cookies, fingerprint protection, and more. Domain profiles always take precedence over the standard profile.

More privacy features:

• Built-in AdBlock, which updates automatically. AdBlock hosts are taken from Steven Black AdBlock hosts: https://github.com/StevenBlack/hosts.
• Third-party cookies can be disabled.
• Block cookie banners.
• Enable or disable Android autofill.
• Delete browser data (on app exit).
• Choose between different search engines (or configure a custom one).
• FOSS Browser itself does not collect any data.


-------------------------------------------------
<b>Bookmarks Filter</b>
-------------------------------------------------

Organize your bookmarks with filters. You can set custom names for each filter. Long press the bookmark icon in the toolbar to get fast access to your favorite bookmarks.


-------------------------------------------------
<b>Gestures</b>
-------------------------------------------------

Assign up to twenty different gestures to the toolbar and toolbar buttons in four directions. Long press buttons to trigger custom events. Supported gestures include: load last website, switch tab, reload, open bookmarks, and many more.


-------------------------------------------------
<b>Backups</b>
-------------------------------------------------

Backup all your important data (bookmarks, history, saved website settings) to your storage. You can also back up app settings and easily restore them on a new installation or device.
