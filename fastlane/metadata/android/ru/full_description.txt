FOSS Браузер это полностью свободный веб обозреватель для Android: приватный и с современным пользовательским интерфейсом. - Ваша конфиденциальность - ваши данные.


-------------------------------------------------
<b>Модульные движки рендеринга (Servo и WebView)</b>
-------------------------------------------------

FOSS Браузер отделяет пользовательский интерфейс от движка рендеринга с помощью модульного слоя абстракции:

• Android System WebView: Стандартный, проверенный движок на базе системной платформы WebKit/Blink.
• Servo Web Engine (Экспериментальный): Независимый встраиваемый движок, написанный на Rust, с параллельным рендерингом через OpenGL ES.
• Переключение на лету: Легко переключайте движки в меню настроек разработчика.


-------------------------------------------------
<b>Внешний вид</b>
-------------------------------------------------

FOSS Браузер использует новейшую библиотеку дизайна Material You. Поддерживает системный режим «День/Ночь» и тему на основе обоев. Пользовательский интерфейс оптимизирован для использования одной рукой: все элементы управления находятся внизу экрана.

Больше возможностей:

• Воспроизведение аудио в фоне.
• Держать экран включённым.
• Открывать ссылки в фоне.
• Восстановление вкладок при перезапуске.


-------------------------------------------------
<b>Конфиденциальность</b>
-------------------------------------------------

FOSS Браузер использует профили доменов для защиты вашей приватности. Для каждого профиля можно настроить: AdBlock, JavaScript, куки, защиту от снятия цифрового отпечатка и многое другое. Сохраненные профили доменов имеют приоритет над стандартным профилем.

Больше функций приватности:

• Встроенный блокировщик рекламы AdBlock с автоматическим обновлением (хосты от Steven Black: https://github.com/StevenBlack/hosts).
• Сторонние куки могут быть отключены.
• Блокировка баннеров куки.
• Включение или отключение Android-Autofill.
• Удаление данных браузера при выходе из приложения.
• Выбор между различными поисковыми системами (или пользовательская настройка).
• Сам FOSS Браузер не собирает никаких данных.


-------------------------------------------------
<b>Фильтр закладок</b>
-------------------------------------------------

Организуйте свои закладки с помощью фильтров. Вы можете установить собственное название для каждого фильтра. Долгое нажатие на значок закладки на панели инструментов открывает быстрый доступ к избранным закладкам.


-------------------------------------------------
<b>Жесты</b>
-------------------------------------------------

Вы можете назначить почти двадцать различных жестов на панель инструментов и её кнопки в четырёх направлениях. Поддерживаются: переход на предыдущий сайт, переключение вкладок, перезагрузка, открытие закладок и многое другое.


-------------------------------------------------
<b>Резервные копии</b>
-------------------------------------------------

Создавайте резервную копию всех важных данных (закладки, история, настройки сайтов) на карте памяти или во внутренней памяти. Резервные копии легко восстанавливаются на новом устройстве.
